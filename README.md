# 🚀 Supriya Deb - Data Scientist Portfolio

A high-performance, dark-romantic themed portfolio showcasing expertise in Data Science, Machine Learning, and AI Engineering. Built for speed, precision, and visual impact.

## ✨ Core Features

### 🎨 Dark-Romantic Crimson Aesthetics
- **Hardware-Accelerated CSS Background**: A smooth, red-glow ambient flow that replaces heavy 3D simulations for maximum performance.
* **Graph Paper Grid Overlay**: A subtle, professional data-science grid that adds depth and texture.
- **Glassmorphism UI**: High-end frosted glass effects with crimson accents.
- **Mobile-First Design**: Fully responsive typography (using `vw` units) and stacking grids.

### 🧩 Specialized Sections
1. **Cinematic Hero** - Dynamic reveal animation with custom easing and blur-to-sharp transitions.
2. **Compact Approach** - A streamlined workflow section (Analyze, Architect, Automate) with custom iconography.
3. **Tech Toolkit** - A minimalist, high-density grid of core technologies (Python, TensorFlow, Snowflake, etc.).
4. **Project Blocks** - A clean 3-column grid featuring integrated GitHub repositories.
5. **Interactive Experience** - A professional timeline with crimson-accented indicators.

### ⚡ Technical Excellence
- **Zero-Lag Performance**: Optimized animations and lightened background patterns.
- **Command Palette (⌘K)** - Quick navigation for power users.
- **Easter Egg** - Hidden surprise for developers.

## 🛠 Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Vanilla CSS + Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Optimized for Vercel

## 🚀 Quick Start

### Installation
1. **Clone the repository**
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Run development server**
   ```bash
   npm run dev
   ```
4. **Build for production**
   ```bash
   npm run build
   ```

## 📁 Project Structure
- `/app` - Next.js App Router and global styles.
- `/components` - Modular React components (Hero, About, Projects, etc.).
- `/public` - Static assets including `resume.pdf`.
